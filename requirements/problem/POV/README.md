# Point of View (POV)

Ein POV-Statement fasst die ausgewählte Perspektive auf ein relevantes Problem zusammen. Es schafft einen gemeinsamen Fokus für die weitere Anforderungsanalyse und die Entwicklung von Lösungsideen. Ein POV beschreibt das Bedürfnis – nicht bereits eine fertige Funktion.

Ein gutes Statement beantwortet:

- **Wer?** Welche konkrete Personengruppe steht im Mittelpunkt?
- **Was?** Welches Bedürfnis hat sie?
- **Warum?** Weshalb ist dieses Bedürfnis bedeutsam?

**Formulierungshilfe:** `[Personengruppe] braucht [Bedürfnis], weil [bedeutsamer Grund].`

Gruppenentwürfe als Markdown-Dateien ablegen, zum Beispiel `pov-gruppe-1.md`. Den gemeinsam ausgewählten Favoriten eindeutig als `ausgewaehlter-pov.md` kennzeichnen.
