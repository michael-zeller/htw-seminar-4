# htw-seminar-4

Gemeinsames Arbeitsrepository für die Anforderungsanalyse im Seminar. Hier sammeln und teilen die Gruppen ihre Ergebnisse als Markdown-Dateien.

## Struktur

- [`requirements/problem/personas/`](requirements/problem/personas/) – Personas als verdichtete Perspektiven auf betroffene Personengruppen
- [`requirements/problem/POV/`](requirements/problem/POV/) – Point-of-View-Statements zur gemeinsamen Problemfokussierung
- [`requirements/solution/`](requirements/solution/) – Qualitätsaspekte und weitere Anforderungen an die Lösung

## Zusammenarbeit

1. Repository lokal auschecken.
2. Gruppenergebnisse als `.md`-Dateien im passenden Ordner ablegen.
3. Aussagekräftige, eindeutige Dateinamen verwenden, zum Beispiel `persona-gruppe-1.md` oder `pov-gruppe-1.md`.
4. Änderungen committen und ins zentrale Repository pushen.

Keine persönlichen oder vertraulichen Daten in Personas aufnehmen. Bei Konflikten oder Unsicherheit die Git-erfahrene Person in der Gruppe um Unterstützung bitten.
